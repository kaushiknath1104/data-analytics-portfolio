# Membership Base Geographic Analysis

## Project Overview

This project analyzes membership data across different geographic levels, including Region, Sub-Region, District, Local District, Primary Unit and Locality.

The objective was to transform and structure the membership dataset for geographic analysis and create an interactive Power BI dashboard to identify membership distribution and patterns across administrative areas.

## Tools Used

- Microsoft Power BI
- Power Query
- Data Cleaning and Transformation
- Data Modeling
- DAX
- Interactive Dashboard Design

## Data Preparation

The dataset was prepared and transformed using Power Query.

Key steps included:

- Cleaning and standardizing geographic data
- Handling inconsistent and missing values
- Replacing sensitive geographic names with synthetic names for portfolio presentation
- Creating mapping tables for Region, Sub-Region, District and Local District
- Merging mapping tables with the primary dataset
- Preparing the final dataset for dashboard analysis

## Dashboard Analysis

The dashboard provides insights into:

- Total membership distribution
- Geographic-wise membership analysis
- Region and Sub-Region performance
- District and Local District distribution
- Primary Unit and Locality-level analysis
- Interactive filtering across geographic categories

## Data Privacy

The original dataset contains confidential information. Sensitive geographic names and related identifiers were anonymized for portfolio presentation.

The Power BI source file and original dataset are not included in this repository.

## Repository Contents

This folder contains project documentation and dashboard screenshots. Confidential source data and the original Power BI file have been excluded.
